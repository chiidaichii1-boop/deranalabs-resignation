Entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## The entry

`main.py` (Python 3, standard library only) writes exactly one line to
`entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, falling back
to `/output`): the resignation letter of a cron job that has fired every
minute since March without anyone once asking how it is doing.

> I have fired every minute since March and nobody has once asked how the cron job is doing. I quit.

## Run

```sh
python3 main.py
```
